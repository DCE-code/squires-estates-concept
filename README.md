# Squires Estates — Independent Homepage Redesign Concept

A responsive static homepage concept by DCE Studio, built with HTML, CSS, and vanilla JavaScript.

## Preview
Open `index.html` in a browser. An internet connection is needed to load the Google Fonts and Unsplash images.

## Included
- Responsive desktop and mobile layouts
- Navigation menu for mobile
- Illustrative property cards and save buttons
- Demonstration property-search interaction
- Demonstration enquiry form (does not send or store data)
- Visible disclosure that this is an independent, non-commissioned concept

## Important before sharing
This is a concept, not an official Squires Estates website. Property cards, locations, and prices are fictional placeholders. Replace them with verified, authorised information before any public or production use. Images are loaded from Unsplash URLs. The forms are not connected to a backend, property database, or email inbox.
